# Sourcing reference — private pool first, public by hand

## Order of operations per role

1. **Private pool** (`ingest`): your CV folder, past applicants, referrals. Zero ToS risk. If this yields 5+ strong, stop — do not go public.
2. **Public, manual-paste only** (`candidate add`): open the live profile in your own signed-in browser, verify must-have recency + lead scope + location, then paste the link plus 2–3 evidence lines. This skill never crawls LinkedIn/GitHub at scale.

## Why manual

- Logged-out LinkedIn search is a walled stub; real results need your session (same lesson as `job-finder`'s playbook). Rate limits and ToS make bulk scraping a ban risk for a solo hunter.
- Snippet-only matching produces false fits (inflated titles, stale stacks). The `unverified` flag exists for exactly this — paste beats snippet.

## What to capture per public profile

- Profile URL (canonical — strip query/hash), current title + company + location
- Years signal (career start → now) or `unknown`
- 2–3 stack evidences with recency ("Angular17 in current role, 2024–now")
- Lead evidence ("led 5-eng pod, delivery owner") or explicit `none found`
- Availability signal only if stated ("open to work" badge, contractor) — never infer from job-hopping

## Outreach (outside this skill)

1. Connection request with a specific note (role, location, why them).
2. Move to email/site only via contact details they publish.
3. Never submit to a `no-unsolicited` client without a requested channel and the candidate's written consent.
4. Never guess work-email patterns; never store passwords or private contact scrapes.
